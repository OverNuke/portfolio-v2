# PROJECT VISION

## Project Name

KEVIN_ARCHIVE_OS

## Concept

A developer portfolio designed as a hybrid between:

- underground fashion archive
- neo-industrial technical catalog
- cyberpunk HUD/FUI interface
- game character selection screen

The website should not feel like a traditional portfolio.

The experience should feel like opening a personal operating system.

---

# Core Principle

The portfolio is an artifact.

The user is not browsing a website.

The user is exploring a system.

---

# Experience Goals

The interface should communicate:

- technical skill
- personality
- experimentation
- design sensitivity

---

# Anti-patterns

Avoid:

- standard hero sections
- infinite scrolling
- SaaS layouts
- rounded cards
- generic gradients
- glassmorphism
- centered landing pages

---

# Main Interaction Model

Single viewport application.

No traditional scrolling.

Navigation happens through:

- panels
- modules
- tabs
- animated transitions
