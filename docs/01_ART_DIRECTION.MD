# ART DIRECTION

## Visual Identity

Keywords:

- HUD / FUI (heads-up display, technical overlay)
- Streetwear from 90s and Y2
- Editorial archive
- Analog digital hybrid

---

# Reference Feeling

The design should resemble:

- fashion technical sheets
- scanned magazines
- experimental UI systems
- game interfaces

---

# Layout Philosophy

Use controlled chaos.

Elements should feel manually assembled.

Characteristics:

- overlapping panels
- asymmetric composition
- cropped images
- technical labels
- annotations
- visual noise

---

# Material Language

Use:

- paper texture
- scan lines
- photocopy artifacts
- grain
- tape effects
- imperfect alignment

Avoid:

- clean corporate perfection
