# Why this exists

Most portfolios are trying to sell something. This one is trying to be
found — like an archive, not a pitch.

The feeling to protect: someone lands on the site the way you'd find a
worn technical spec sheet tucked inside a garment, or a scanned page
from a magazine nobody reprinted. Not designed to be liked instantly.
Designed to reward looking closely.

---

# Where it comes from

Two references started this, and neither is a website.

**The akatachi wldd product sheet** — a fashion tech sheet, not a
storefront. Photos taped down, not laid out. A halftone grain that
proves it was printed and scanned, not exported. Black ink labels
doing the job a UI component would do on a normal site — "Rubber Stone
Washed & Hand Waxed" instead of a feature bullet. A price handwritten
on a torn scrap, sitting right next to type set with total precision.
That contrast — exacting in some places, human and uneven in others —
is the whole feeling.

**The Metal Sonic panel sheet** — comic pages, not dashboards, but
built like one. Panels of different weight and size doing different
jobs on the same page, a bold running title as structure rather than
decoration, no pretense that everything has to be the same size to be
organized. That's where "no scroll, panels instead of sections" comes
from — not from software dashboards, from how a page of comic art
gets you to look at six things without ever asking you to scroll.

Underneath both: HUD/FUI tech-manual graphics, neo-industrial parts
catalogs, and the specific feeling of a game's character-select or
boot screen — interfaces that assume you're capable, and don't
apologize for having texture.

---

# What it should evoke

- The feeling of opening a personal system, not a marketing page.
- Precision next to imperfection — a grid that's clearly intentional,
  broken deliberately in specific places, never accidentally.
- Confidence without noise. Density without clutter.
- "This person built the container as carefully as the contents."

# What it should never become

- A SaaS landing page wearing a black-and-white skin.
- Aesthetic for its own sake — every texture, panel, and label still
  has to say something true about the work or the person.
- So obscure that it stops functioning as a portfolio. The visitor is
  still here to find out if you're good and how to reach you — the
  archive framing is a lens, not an excuse to hide the point.
- Inaccessible in the name of atmosphere. Grain and asymmetry are
  choices about surface, not reasons to drop contrast, keyboard
  support, or reachable targets. If a WCAG requirement and a mood
  choice conflict, MASTER_AGENT.md's conflict order already settled
  it — accessibility wins, every time, without resentment.

---

# The tension this project lives inside

No-scroll and WCAG's reflow requirement pull against each other. Dense
technical labels and 24px touch targets pull against each other. A
project built to feel handmade still has to be maintainable by one
person editing it alone at midnight six months from now.

None of these are contradictions to hide. They're the actual design
problem. Solving them well — not picking one side and pretending the
other doesn't exist — is what makes this a portfolio piece in its own
right, not just a container for other portfolio pieces.
