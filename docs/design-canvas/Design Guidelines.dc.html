[03] foundations

Grain, Dots, Wash

  • Paper mode keeps its hatch + halftone + print-grain (see Legacy → Ink-Flow Background).
  • Dark mode gets a blueprint dot-grid instead: small dots, ~24px cell, low-opacity white on near-black — the backdrop every blob specimen and the cursor demo sits on.
  • Imagery goes grayscale ink-wash: desaturated, higher contrast, soft vignette. No more torn-clip masks on photos — a clean rectangle plus a corner-bracket frame (see Frames).

Blob Shape Language

The system's new motion primitive — metaball shapes built from overlapping circles or asymmetric border-radius, numbered like lab specimens. Buttons, nav, cards, cursor and dividers all pull from this vocabulary; nothing is a plain circle except the smallest "cell" state.

[05] foundations

Corner-Bracket Frames

Replaces torn edges as the containment language: four short L-brackets, one per corner, inset ~10px, 1.5px stroke. Works on photos, panels, and image placeholders in both modes.

[06] foundations

Slow Ink, Living Cells

Ambient loops stay 24–46s ease-in-out. Interactive still resolves in .2–.35s on cubic-bezier(.2,.85,.2,1). New: blob morphs cycle 3–4 border-radius keyframes rather than a single before/after state. Cursor lag is the one allowed exception to "no springy easing" — ~120ms ease-out, just enough to feel alive, never bouncy.

[09] rules

Desktop Canvas → Mobile Flow

  • ≥1200px — fixed 1440×900 absolute canvas, as built, either mode.
  • 720–1199px — same layout, scaled fluidly; type shrinks ~15–20%.
  • <720px — stack in reading order, single column, full-width panels.
  • Dot-grid cell doubles to ~40px below 720px to avoid moiré on small screens.
  • Blob morphs simplify to a plain scale pulse (no border-radius keyframes) on touch/low-power.
  • Custom cursor has no meaning on touch — swap for a static blob icon or drop it entirely.
  • Type floor: serif H1 never below 32px; body 14–16px; mono labels floor at 11px.
  • Touch targets minimum 44px.
[10] content

Voice, EN / ES

Unchanged from v1: first-person, dry, metadata-style captions over marketing copy. EN and ES carry the same register in both directions — structure and numbering stay identical, only sentence content swaps via the existing COPY table pattern.

[11] direction

Seinen, Now Editorial

The seinen call still stands — serious, restrained, high-contrast — and this pass reinforces it: grayscale ink-wash imagery and quiet corner-bracket frames read closer to an editorial print portfolio than a comic panel. No logo yet; wordmark stays typographic, now set in Instrument Serif italic.
