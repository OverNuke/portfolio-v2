Two new pieces, one existing palette

Component A is the red brand-square from the streetwear reference — rebuilt as a hanko seal: Signal Red surface, Paper White kanji, micro roman registration row. COMPONENT A

THE SEAL — kanji stamp on Signal Red

  • Kanji 記録 (kiroku — “record / archive”), vertical mincho, upright orientation. Reads as a carved stamp, not typeset UI.
  • Paper White on Signal Red — 4.74:1, the pair already documented for .bar--accent. No new color, no new pair.
  • Always decorative: whole component is aria-hidden, never focusable, never the only carrier of any information. It is chrome with attitude.
  • Two sizes: 148px (sheet mark) and 92px (stamp-in-margin). Rotation obeys the ±2° cap.
  • Budget rule: max one seal per screen, and it shares the screen’s red budget — if a louder red callout exists, the seal moves to a margin or comes off.

ZENRYOKU · FULL POWER↑↑↓↓←→←→BA Hard lines: Born to win. No save points. Zenryoku — full power.
  • The real information is the red strip — STATUS / OPEN TO WORK. Normal DOM text, never aria-hidden, never shed at narrow widths. Everything else is poster voice.
  • Ink-inverse on Ink ≈16.9:1; Paper White on Signal Red strip 4.74:1. Both pass AA at any size.
  • Kanji 全力 (zenryoku — “full power”) is decorative and aria-hidden; its romanization sits in the visible micro row, so no meaning lives only in Japanese.
  • Easter eggs stay in the micro layer: the Konami row, print numbers, hype lines. Screen readers get one clean sentence via a .visually-hidden summary.
  • Swappable line sets (see usage): the square is a format, not one fixed poster.
USAGE

Line sets + placement across screens

  • Home: the type square replaces the status / open to work accent plate 1:1 (same grid pocket, top-right). The second accent plate (build) stays a bar — two squares would fight.
  • Line set A (Home): BORN 2 WIN / NO SAVE POINTS / 全力 / status strip OPEN TO WORK.
  • Line set B (Contact): INSERT COIN / TO CONTINUE / 連絡 (renraku — “contact”) / strip CHANNELS OPEN.
  • Line set C (Projects, optional): SHIPPED > PERFECT / NEW GAME+ / 出荷 (shukka — “shipment”) / strip 3 RECORDS.
  • Seal placement: Profile top-right beside the name (the reference position: square beside the figure); Contact bottom margin as the “document stamp.” Never two per screen.
  • Red budget per screen (doc 12 rule): one loud red element, two only when both carry distinct real info. Seal is decorative, so a red strip in the type square + a seal on the same screen = the seal must be the quiet one (small size, margin position).
